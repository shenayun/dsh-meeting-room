# dsh-meeting-room · 会议室

把几个外部大模型请到一张桌子上：**叫到才发言，按顺序接话，人拍板。**

这是给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 用的插件。它不依赖任何别的插件，只读自己的数据目录——装上就是它，卸掉也只有它。

> 为什么叫「会议室」而不是「圆桌」：圆桌强调平等表决，但这里**没有人投票**。桌上的人只出观点，判断和决定在你这儿。

---

## 它做什么

你在对话里说一句，助手回一句；然后**桌上开着的那几位按顺序各说一句**。他们看得见前面谁说了什么，也被要求逐条评价别人的话，而不是各说各的。

你随时可以：

- 让某一位**闭嘴**（这一场不参与），再点一下让他**开口**；
- 一键**全部闭嘴**，就你和助手说话；
- 点名让某一位单独说一句。

**开着会议室 = 允许他们参与；不点开 = 一个都不出声。** 不注入、不插话、不订阅，不会在你聊天时突然冒出来。

顺序固定：**你 → 助手 → 顾问（按入座顺序）**。

---

## 安装

### 桌面版

1. 打开侧边栏 **插件** → **添加插件** → **安装第三方插件**
2. 填本地目录（解压后的文件夹），或填 Git 仓库地址
3. **完全重启** DeepSeek Harness
4. 重启后在 **设置 → 会议室** 里请人

装完不用改任何配置文件，数据目录会自动建在 `~/.dsh/meeting-room/`。

---

## 请一位顾问

打开 **设置 → 会议室**：

1. **从 DSH 已配的模型里挑**（如果下拉里有）——自动填好地址和模型名，只剩密钥要填。注意：DSH 的配置里只有环境变量名，**密钥不会自动带过来**。
2. 或者**选一个提供商**：本机网关 / DeepSeek / OpenAI / Kimi / 智谱 / 自定义。地址会自动填，可以改。
3. **填 API 密钥**，点 **获取模型**：
   - 列出多个 → 从下拉里选一个；
   - 列不出来 → **直接手填模型名**（很多中转站不提供模型列表）。
4. 点 **添加**。

**只支持 OpenAI 兼容协议**（`/chat/completions`）。Anthropic 的消息格式不一样，暂不支持。

**一把 key 可以加多个模型**——比如同一家的 `glm-5.3` 和 `glm-5.3-flash` 各占一位，方便对比。重名自动编号（`Glm`、`Glm-2`）。

名额：**名单最多 30 位**（不同的事请不同的人），**同一场最多 6 位**（加上助手正好七个，再多就听不清了）。

## 界面

### 设置页「会议室」

名单、总闸、加人、改名、移除。每个顾问前面一个圆点：**实心绿 = 会说话，空心 = 不说话**。

### 对话输入框下面一条

`▸ 会议室 · N 位顾问`，点开是一块浮层：

- **默认钉在右边**，上下留边，不盖按钮也不压输入框；
- **拖标题栏可以浮动**到任意位置，浮动时点 **⌖** 贴回右边；
- 上面是控制区（开关、顾问胶囊、全部闭嘴），**钉住不动**；
- 下面是发言区，**只有这一块滚**；贴着底部时新内容自动跟上，你往上翻看旧内容时它不打扰你。

顾问压成胶囊：**绿框 = 正在说话**，点一下切换。鼠标停上去能看到模型名和「点一下让他闭嘴 / 开口」。

## 它怎么记得住

模型自己没有记忆，每次请求都是全新的。所以连贯性由插件喂：

- 每句话存 `history/<名字>.json`，**最多留 5 轮**；
- 下次请求时，**把它自己说过的话以 `assistant` 回合原样放回去**——不是拼成一段文字塞给 `user`，那是转述，它不认得；
- 散场（`close`）就把历史清掉，不带到下一场。

---

## 视角由它们自己定

不预设人设、不分配角色。提示词里只要求：

- 想清楚了，开头说一句「我从哪个角度看这件事，为什么」；
- 没想清楚就不说，直接讲看法；
- 讨论中途想到可以补，觉得不合适可以换——换的时候说一句为什么。

给它们分配视角，等于替它们想好了要说什么，剩下的只是表演。

## 数据

全在 `~/.dsh/meeting-room/`：

| 文件 | 是什么 |
|---|---|
| `config.json` | 名单、总闸、网关地址 |
| `current.json` | 这一场谁在、问过几轮、上一轮说了什么 |
| `history/*.json` | 每位顾问自己的对话历史（最多 5 轮） |
| `hall-<日期>.jsonl` | 每句话的流水：谁、问的什么、答的什么、成没成 |
| `meeting-room.log` | 插件自己的运行日志 |

**API key 是明文**，只存在这个目录里，不上传、不外发。这台机器要借给别人之前，记得把 `config.json` 清掉。

---

## 花的是你们的钱

每说一轮，每位开着的顾问都要调一次接口，**按你自己在那些平台的账户计费**。插件看不到它们的余额，也管不了额度。

- 从关到开会拦一次，说明这件事；
- 随时可以「全部闭嘴」，一键停支出。

---

## 会过滤掉的东西

会议室只听见「你说的话」和「助手的回复」。下面这些系统注入会自动跳过：

长期记忆注入、记忆反思任务、运行时快照（`Current runtime context` / `Time sampled…`）、交接单、渠道前缀（`[渠道：微信]`）等。

而且是**按轮配对**的：如果某一轮整轮都是系统注入，这一轮整个丢掉——不会拿上一轮的问题配这一轮的回答。

---

## 给助手用的工具

对话里由一个工具管，普通用户不用管：

| action | 做什么 |
|---|---|
| `enable` / `disable` | 开关总闸 |
| `open` | 请人入座；不给名字就请开着的那几位 |
| `speak` | 就一个问题按顺序各说一次（`who` 可只点一个人） |
| `close` | 散场，对话历史一起清 |
| `status` | 看谁在、刚说过什么 |

---

## 已知限制

- **只支持 OpenAI 兼容协议**；Anthropic 原生协议不支持。
- 每轮每位顾问都是一次独立请求，**真花钱**。
- 侧栏是自绘浮层，不是宿主原生面板（原生面板要宿主自己派发 key，插件开不了）。
- 插件**不总结、不投票、不下判决**——它只把每个人说的话摊开，结论由用它的助手给，人拍板。
- 目前**没有自动化测试**。
